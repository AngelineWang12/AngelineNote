# MA20 / MA60 双均线策略笔记

## 1. MA20 和 MA60 是什么

MA 是 Moving Average，移动平均线。

```text
MA20 = 最近 20 个交易日收盘价的平均值
MA60 = 最近 60 个交易日收盘价的平均值
```

可以简单理解为：

```text
MA20 代表中短期市场成本
MA60 代表中期市场成本
```

如果当前价格或短期均线在长期均线之上，通常说明近期走势比较强；如果短期均线在长期均线之下，通常说明近期走势比较弱。

## 2. MA20 / MA60 双均线的核心原理

双均线策略的基本想法是：用短期趋势和长期趋势的相对位置判断市场状态。

常见规则：

```text
MA20 > MA60：认为趋势偏强，买入或持有
MA20 < MA60：认为趋势偏弱，卖出、减仓或转入防守资产
```

背后的逻辑是趋势跟随：

```text
上涨趋势可能继续上涨
下跌趋势可能继续下跌
```

它不是低买高卖策略，而是等趋势变强之后再进场，趋势变弱之后再离场。

## 3. 金叉和死叉

在双均线策略中，经常会看到两个词：

```text
金叉：短期均线从下往上穿过长期均线
死叉：短期均线从上往下穿过长期均线
```

对应到 MA20 / MA60：

```text
MA20 上穿 MA60：金叉，可能是买入信号
MA20 下穿 MA60：死叉，可能是卖出信号
```

不过实际写策略时，不一定非要判断“穿越瞬间”，也可以直接判断：

```text
MA20 > MA60：保持持仓
MA20 < MA60：保持空仓或低仓位
```

## 4. 适合什么类型的基金

MA20 / MA60 更适合有明显趋势特征、交易流动性较好的场内基金。

相对适合：

```text
宽基指数 ETF：沪深300ETF、中证500ETF、创业板ETF
商品 ETF：黄金ETF
部分海外指数 ETF：纳指ETF、标普500ETF、恒生ETF
```

不太适合：

```text
成交很少的冷门 ETF
费用较高、无法日内交易的场外基金
长期横盘震荡的品种
容易受短期消息剧烈扰动的主题基金
```

## 5. 它的优点

MA20 / MA60 的优点是简单、直观、容易执行。

主要优点：

```text
规则清楚，不依赖主观判断
可以过滤一部分下跌趋势
适合用来学习回测、信号、仓位、交易日志
容易和买入持有、定投策略做对比
```

对新手来说，它最大的价值不是一定能赚钱，而是能帮你理解“策略规则如何转化成买卖行为”。

## 6. 它的缺点

双均线策略最大的问题是滞后。

因为均线是历史价格的平均值，所以它一定比真实价格变化慢：

```text
上涨初期：可能还没买入，容易错过一段涨幅
下跌初期：可能还没卖出，容易吃到一段回撤
震荡行情：可能反复金叉死叉，频繁亏小钱
```

所以 MA20 / MA60 适合趋势明显的行情，不适合上下反复的震荡行情。

## 7. 全仓 / 空仓的问题

很多入门策略会写成：

```text
MA20 > MA60：全仓买入
MA20 < MA60：全部卖出
```

这个规则很清楚，但也比较激进。

问题在于：

```text
如果信号判断错了，容易完全错过上涨
如果刚买入就反转，亏损会比较明显
长期空仓时，可能跑输买入持有
```

更温和的方式是把它改成仓位调节：

```text
MA20 > MA60：保持 70% - 80% 仓位
MA20 < MA60：保持 20% - 30% 仓位
```

这样即使策略判断错，也不会完全离场。

## 8. 和定投、买入持有的关系

MA20 / MA60 属于择时策略。

它试图回答：

```text
现在该不该持有？
现在该不该减仓？
```

定投和买入持有则更关注长期配置：

```text
定投：不预测短期走势，分批买入
买入持有：相信资产长期上涨，长期承受波动
```

对基金投资来说，MA20 / MA60 不一定比定投或买入持有更好。它需要通过回测比较：

```text
是否提高收益？
是否降低最大回撤？
是否减少心理压力？
是否会长期跑输基准？
```

如果一个均线策略长期跑输买入持有，就不能因为它“看起来专业”而继续使用。

## 9. 回测时要重点看什么

不要只看最终收益。

至少要看：

```text
策略收益
基准收益
超额收益
最大回撤
交易次数
胜率
盈亏比
夏普比率
是否长期空仓
是否只靠某一段行情赚钱
```

尤其要关注：

```text
最大回撤是否真的降低
是否跑赢买入持有
交易次数是否过多
参数稍微变化后是否仍然有效
```

## 10. 参数不要乱调

MA20 / MA60 只是一个常见组合，不是神奇参数。

可以做少量对比：

```text
MA10 / MA30
MA20 / MA60
MA20 / MA120
```

但不要为了让历史收益更好而不断试参数。

如果参数换一换结果就完全崩掉，说明策略可能只是过拟合历史数据。

## 11. 更稳妥的改进方向

如果 MA20 / MA60 全仓空仓效果不好，可以考虑这些方向：

### 仓位调节

```text
MA20 > MA60：80% 沪深300ETF + 20% 货币ETF
MA20 < MA60：30% 沪深300ETF + 70% 货币ETF
```

### 加防守资产

```text
趋势强：持有沪深300ETF
趋势弱：转入黄金ETF、债券ETF或货币ETF
```

### 降低交易频率

```text
每天判断改为每周或每月判断
```

这样可以减少噪音和频繁交易。

## 12. 学习结论

MA20 / MA60 是一个很适合入门的策略，因为它简单、可解释、容易回测。

但它不是稳赚策略，也不是万能策略。

它真正教会你的东西是：

```text
趋势策略为什么会滞后
为什么震荡市容易亏损
为什么要和基准比较
为什么最大回撤比收益更重要
为什么复杂策略不一定比定投更好
```

对基金量化学习来说，正确用法是：

```text
把 MA20 / MA60 当成理解趋势和择时的练习工具
不要直接把它当成实盘赚钱系统
先回测，再模拟盘，再考虑小额实盘
```
